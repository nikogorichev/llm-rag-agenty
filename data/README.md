# Пример корпуса — Основы машинного обучения

В этом каталоге находится небольшой пример корпуса, который используется в **модулях 04 и 05** для упражнений с эмбеддингами и поиском, а также преподавателем курса.

# # Тематика

Шесть автономных документов Markdown на тему **основ машинного обучения**, в которых рассматривается путь от базовых концепций до методов, лежащих в основе современных LLM и систем RAG:

| Файл | Тема |
| --- | --- |
| `corpus/01-what-is-machine-learning.md` | Парадигмы ML, функции потерь, переобучение |
| `corpus/02-neural-networks.md` | Слои, обратное распространение, CNN / RNN / Transformers |
| `corpus/03-embeddings.md` | Word2Vec, контекстуальные эмбеддинги, косинусное сходство |
| `corpus/04-transformers-and-attention.md` | Механизм внимания, multi-head attention, декодер-только LLM |
| `corpus/05-training-and-fine-tuning.md` | Предобучение, SFT, RLHF, LoRA |
| `corpus/06-retrieval-augmented-generation.md` | Конвейер RAG, режимы сбоев, оценка |

Каждый документ содержит примерно 200–300 слов — этого достаточно, чтобы документ свободно помещался в один чанк во время упражнений модуля 04, но при этом в нём содержалось достаточно уникальной семантической информации, делающей поиск релевантным.

# # Как модули 04 и 05 используют этот корпус

- **Модуль 04** строит эмбеддинги для всех шести документов в векторном индексе, хранящемся в памяти, а затем выполняет запросы ближайших соседей для демонстрации семантического поиска. Документы достаточно короткие, чтобы вы могли вручную просмотреть каждый извлеченный вектор.
- **Модуль 05** строит полный конвейер RAG на том же корпусе: разбиение на чанки → эмбеддинги → извлечение → (опционально реранкинг) → генерация. Небольшой размер позволяет выполнять полную оценку (eval) с минимальными затратами.

# # Рекомендуемые тестовые вопросы

Эти вопросы отлично подойдут для дымовых тестов (smoke tests) вашего пайплайна поиска, так как ответ на каждый из них четко содержится в одном конкретном документе:

| Вопрос | Ожидаемый документ-источник |
| --- | --- |
| В чем разница между обучением с учителем и без учителя? | `01-what-is-machine-learning.md` |
| Как обратное распространение вычисляет градиенты в нейронной сети? | `02-neural-networks.md` |
| Почему Word2Vec создает один вектор на слово независимо от контекста? | `03-embeddings.md` |
| Какова математическая формула для scaled dot-product attention? | `04-transformers-and-attention.md` |
| Что такое LoRA и зачем он используется для fine-tuning? | `05-training-and-fine-tuning.md` |
| Каковы два основных режима сбоя в пайплайне RAG? | `06-retrieval-augmented-generation.md` |

В хорошо настроенной системе правильный документ должен возвращаться как топ-1 результат для каждого из этих вопросов. Если это не так, попробуйте изменить размер перекрытия чанков (chunk overlap), использовать реранкинг или более мощную модель эмбеддингов.

# # Расширение корпуса

Добавьте больше файлов `.md` в каталог `corpus/` и выполните переиндексацию. Модули настроены так, чтобы автоматически подхватывать любые файлы, соответствующие шаблону `corpus/*.md`, поэтому изменение кода не требуется.
