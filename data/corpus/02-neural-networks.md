# Нейронные сети

Нейронная сеть — это модель машинного обучения, структура которой отдалённо вдохновлена биологическим мозгом. Она организована в виде **слоёв** вычислительных элементов, называемых нейронами. Каждый нейрон вычисляет взвешенную сумму своих входов, добавляет смещение (bias) и пропускает результат через нелинейную **функцию активации**, такую как ReLU или сигмоида. Стекирование множества слоёв позволяет сети строить всё более абстрактные представления входных данных.

# # Основы архитектуры

Первый слой — это **входной слой** — по одному узлу на каждый исходный признак (например, одно значение пикселя на пиксель в изображении). Скрытые слои в середине извлекают признаки. **Выходной слой** выдаёт предсказание: одно число для регрессии или распределение вероятностей по классам для классификации (используя активацию softmax).

Полносвязный, или **dense** (плотный), слой соединяет каждый нейрон с каждым нейроном предыдущего слоя. Специализированные архитектуры ограничивают эту связность ради эффективности и индуктивного смещения:

- **Сверточные нейронные сети (CNN)** разделяют веса (share weights) между пространственными позициями, что делает их эффективными для данных изображений и аудио.
- **Рекуррентные нейронные сети (RNN)** передают скрытое состояние от одного временного шага к следующему, обрабатывая последовательные данные.
- **Трансформеры** используют механизмы внимания (без рекуррентности) и стали доминирующей архитектурой для задач обработки языка, зрения и мультимодальных задач.

# # Обучение

Обучение настраивает веса сети для минимизации функции потерь. Основной алгоритм — **обратное распространение** (backpropagation): правило дифференцирования сложной функции применяется послойно для вычисления градиента потерь по отношению к каждому весу. Оптимизатор — чаще всего **Adam** или **SGD с импульсом (momentum)** — затем сдвигает каждый вес в направлении, уменьшающем функцию потерь.

Современные сети могут иметь миллиарды параметров. Для их обучения требуются GPU или TPU, большие наборы данных и тщательная настройка гиперпараметров (learning rate, размер батча, weight decay).
