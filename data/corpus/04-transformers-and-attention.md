# Трансформеры и механизм внимания

Архитектура Transformer, представленная в 2017 году в статье «Attention Is All You Need», вытеснила рекуррентные сети и стала доминирующей моделью для задач с последовательностями. Каждая крупная большая языковая модель (LLM) — GPT, Claude, Llama, Gemini — является Трансформером.

# # Механизм внимания

Attention позволяет модели взвешивать каждый токен во входных данных при вычислении представления любого заданного токена. Для каждого токена вычисляются три вектора: **query** (Q), **key** (K) и **value** (V). Выход для токена — это взвешенная сумма всех векторов значений, где веса берутся из скалярного произведения query этого токена с key каждого другого токена, пропущенного через softmax.```
Attention(Q, K, V) = softmax(QKᵀ / √d_k) V
````d_k` — это размерность ключа; масштабирование с квадратным корнем предотвращает слишком сильный рост скалярных произведений, из-за которого softmax мог бы насыщаться.

**Multi-head attention** выполняет несколько операций внимания параллельно с разными обучаемыми проекциями, затем конкатенирует и проецирует результаты. Каждая голова может специализироваться: например, одна отслеживает синтаксическое согласование, другая — дальний референс.

# # Блоки Transformer

Слой Transformer состоит из:
1. Multi-head self-attention (с residual-связью и layer norm).
2. Feed-forward network, применяемой поэлементно (два линейных слоя с ReLU или GELU
   между ними), также с residual-связью и layer norm.

**Positional encodings** (или обучаемые positional embeddings) добавляются к входу
перед первым слоем, так как само по себе внимание инвариантно к перестановкам и без этих кодировок игнорирует порядок токенов.

# # LLM только с декодером

LLM вроде GPT и Llama используют только декодерную часть. Они обучаются авторегрессионно:
на каждой позиции они предсказывают следующий токен при условии всех предыдущих токенов. Это достигается с помощью **causal (masked) attention** — каждый токен можетAttend только к токенам, которые шли перед ним, что предотвращает «подглядывание» модели вперёд во время обучения.
