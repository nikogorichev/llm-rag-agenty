# # Понятия

## # 1. Линейная регрессия, нормальное уравнение и градиентный спуск

Мы моделируем целевую переменную `y` как линейную функцию признаков `X` плюс шум. Если мы включим свободный член в веса (добавим столбец из `1` слева к `X`, так что `w[0]` — это bias), модель выглядит так:

```
ŷ = X w
```

Мы измеряем ошибку с помощью **среднеквадратической ошибки (MSE)**:

```
L(w) = (1/N) · ||X w - y||²  =  (1/N) · Σ_i (x_iᵀw - y_i)²
```

MSE — это выпуклая гладкая чаша относительно `w`, поэтому она имеет единственный глобальный минимум. Приравняйте градиент к нулю, чтобы найти его. Градиент равен:

```
∇L(w) = (2/N) · Xᵀ (X w - y)
```

Приравняв ∇L = 0 и сократив константу, получаем **нормальное уравнение**:

```
XᵀX w = Xᵀ y        →        w = (XᵀX)⁻¹ Xᵀ y
```

**Никогда не вычисляйте обратную матрицу.** Вычисление `(XᵀX)⁻¹` выполняется медленнее и численно менее устойчиво, чем прямое решение системы линейных уравнений. Сформируйте `A = XᵀX` и `b = Xᵀy`, затем решите `A w = b` с помощью решателя на основе LU-разложения (`np.linalg.solve` в numpy; в TS-обвязке предоставлена небольшая функция `solve()`, использующая метод Гаусса).

Аналитическое решение является точным, но требует `O(D³)` операций и хранения всего набора данных в памяти. **Градиентный спуск** находит тот же минимум итеративно, выполняя по одному недорогому шагу за раз:

```
w ← w - lr · ∇L(w) = w - lr · (2/N) · Xᵀ (X w - y)
```

При адекватной скорости обучения для стандартизированных признаков градиентный спуск (GD) монотонно движется вниз к тому же `w`, что даёт нормальное уравнение.

**R² (коэффициент детерминации)** — это безразмерный показатель качества подгонки:

```
R² = 1 - SS_res / SS_tot
   SS_res = Σ (y_i - ŷ_i)²      (error the model still makes)
   SS_tot = Σ (y_i - ȳ)²        (error of just predicting the mean)
```

`R² = 1` — идеальная подгонка; `R² = 0` не лучше предсказания среднего значения; отрицательное значение говорит о том, что модель хуже среднего.

## # 2. Смещение–дисперсия, кросс-валидация и Ridge-регуляризация

Построим полином степени `d`, сформировав признаки `φ(x) = [1, x, x², …, x^d]` и применив метод наименьших квадратов к `Φ`. По мере увеличения `d` модель способна описывать больше форм, но эта гибкость играет двоякую роль. Ожидаемая ошибка на тесте разлагается на три составляющие:

```
E[(y - ŷ)²] = bias² + variance + irreducible_noise
```

- **Высокий сдвиг / недообучение** (low `d`): модель слишком проста, чтобы уловить сигнал, поэтому она плохо показывает себя и на _обучении_, и на _тесте_.
- **Высокая дисперсия / переобучение** (high `d`): у модели достаточно свободы, чтобы подстроиться под _шум_ в обучающей выборке. Ошибка на обучении продолжает падать к нулю, но ошибка на тесте растет, так как подогнанные «изгибы» не обобщаются.

Если построить график ошибки на тесте в зависимости от `d`, получится классическая **U-образная кривая**: она падает (сдвиг уменьшается), достигает минимума в точке баланса, а затем растет (дисперсия увеличивается).

Во время обучения мы не можем видеть ошибку на тесте, поэтому оцениваем её с помощью **k-fold cross-validation**. Разделим данные на `k` фолдов; для каждого фолда обучаемся на остальных `k-1` и оцениваем на отложенном фолде; усредняем `k` полученных оценок:

```
CV_MSE(d) = (1/k) · Σ_{f=1..k}  MSE( model trained on all folds but f,  fold f )
```

Кривая CV (перекрёстной проверки) повторяет ту же U-образную форму, что и истинная ошибка на тесте, поэтому её минимум подсказывает, какую степень выбрать, используя только обучающие данные.

**Ридж-регуляризация (L2)** напрямую борется с дисперсией, штрафуя большие веса:

```
L_ridge(w) = ||Φ w - y||² + λ · Σ_{j≥1} w_j²
```

Обратите внимание на `j ≥ 1`: мы **не штрафуем свободный член** `w[0]` — сжатие смещения (bias) без веской причины притянуло бы предсказания к нулю. Аналитическое решение — это нормальное уравнение, к диагонали которого добавлена `λ` (кроме элемента, соответствующего смещению):

```
w = (ΦᵀΦ + λ R)⁻¹ Φᵀ y ,      R = I  but  R[0,0] = 0
```

Большее `λ` → меньшее `||w||` → более гладкая функция → меньше дисперсии (ценой небольшого смещения). При фиксированной высокой степени правильное `λ` уменьшает норму весов _и_ снижает ошибку CV. `λ = 0` возвращает обычный метод наименьших квадратов.

## # 3. Логистическая регрессия (бинарная) и L2

Для бинарной классификации нам нужна **вероятность**, а не сырая оценка. Пропустите линейную оценку `z = X w` через **сигмоиду**:

```
σ(z) = 1 / (1 + e^{-z})        (squashes ℝ → (0, 1))
p = σ(X w) = P(class = 1 | x)
```

Предсказывай класс 1 при `p ≥ 0.5`. Правильная функция потерь — **binary cross-entropy** (log loss), отрицательный логарифм правдоподобия меток:

```
L = -1/N · Σ_i [ y_i · log(p_i) + (1 - y_i) · log(1 - p_i) ]
```

Если истинная метка равна 1 и `p → 1`, `log(p) → 0` (нет потерь); если `p → 0`, `log(p) → -∞` (огромные потери). Ограничьте `p` интервалом `[ε, 1-ε]`, чтобы `log` никогда не вычислялся от ровно 0 или 1.

Градиент изящно прост — структурно идентичен линейной регрессии, просто с сигмоидой внутри `p`:

```
∇L = (1/N) · Xᵀ (σ(X w) - y)
```

(«разность предсказания и целевого значения», скалярно умноженная на признаки.) L2-регуляризация добавляет `(λ/N) · w` к градиенту, снова **с обнуленным элементом смещения**:

```
grad = (1/N) · Xᵀ (p - y) + (λ/N) · w      (but grad[0] gets no L2 term)
```

Больший `λ` уменьшает `||w||`. На линейно разделимых данных веса без регуляризации стремятся уйти в бесконечность (чтобы прижать `p` точно к 0/1); L2-регуляризация сдерживает их.

## # 4. Метрики ранжирования (ROC/AUC) и кластеризация (k-means)

**Классификатор выдаёт оценки, а не только метки.** _Порог_ (threshold) превращает оценку в решение. При сдвиге порога меняется баланс между обнаружением положительных примеров и ростом ложных срабатываний. Для порога `t` (предсказываем положительный класс, если `score ≥ t`):

```
TPR(t) = TP / (TP + FN)   — true-positive rate  (a.k.a. recall / sensitivity)
FPR(t) = FP / (FP + TN)   — false-positive rate (1 − specificity)
```

Перебираем `t` от большего к меньшему и строим график `(FPR, TPR)`: это **ROC-кривая**.
Она всегда проходит от `(0, 0)` (порог выше всех оценок — не предсказываем положительный класс ни для одного объекта) до `(1, 1)` (порог ниже всех оценок — предсказываем положительный класс для всех объектов).

**AUC** — это площадь под этой кривой, вычисленная методом трапеций:

```
AUC = Σ_i (fpr[i+1] - fpr[i]) · (tpr[i+1] + tpr[i]) / 2
```

У AUC есть замечательная интерпретация: это вероятность того, что случайно выбранный положительный пример получит оценку выше, чем случайно выбранный отрицательный. Она **не зависит от порога**, поэтому измеряет качество ранжирования независимо от того, где вы установите порог отсечения:

```
perfect ranker  → AUC = 1.0
random ranker   → AUC ≈ 0.5     (the diagonal)
reversed ranker → AUC = 0.0
```

**k-means (алгоритм Ллойда)** — обучение без учителя: без меток, просто группирует `N` точек в `k` кластеров по близости. Он чередует два шага, пока ничего не изменится:

```
assign:  for each point x_i, pick the nearest centroid   cluster(i) = argmin_k ||x_i - c_k||²
update:  move each centroid to the mean of its points     c_k = mean{ x_i : cluster(i) = k }
```

Целевая функция, которую она минимизирует, — **инерция**, сумма квадратов внутрикластерных расстояний:

```
inertia = Σ_i ||x_i - c_{cluster(i)}||²
```

Оба этапа могут только уменьшить (или сохранить) инерцию, поэтому значение инерции **монотонно не возрастает**, и алгоритм всегда сходится — хотя, возможно, к _локальному_ минимуму, поэтому важна инициализация. (В тестовом окружении используется инициализация в стиле farthest-first / k-means++, чтобы распределить начальные центроиды по сгусткам данных.)
