# Module 01c — Основы глубокого обучения

> **Метки глубины** 🟢 app-level · 🟡 build-one-piece-by-hand · 🔴 from-scratch

Это этап собеседования «Основы глубокого обучения», основанный на первых принципах.
Работа с современными LLM (Large Language Models, большими языковыми моделями) опирается на стек идей, появившихся до трансформеров: **обратное распространение ошибки** (chain rule, применённый в обратном порядке), **оптимизаторы** (SGD (Stochastic Gradient Descent, стохастический градиентный спуск) → momentum (импульс) → Adam (Adaptive Moment Estimation)), **инициализация весов** (He / Xavier), **регуляризация** (dropout, batchnorm, L2) и **рекуррентные сети** (способ моделирования последовательностей до появления трансформеров). В этом модуле каждая из этих идей реализуется на чистом numpy (Python) и обычных массивах (TypeScript) — без ML (Machine Learning, машинного обучения) фреймворков, без сетей и без LLM. Всё выполняется детерминированно с фиксированными си́дами; данные генерируются прямо в коде.

Чему этот модуль сознательно **не** учит повторно:

- **2-D свёртка** — этим занимается модуль 09. Здесь свёрток нет.
- **Одиночная голова внимания** — этим занимается модуль 01. Вместо этого мы разбираем _рекуррентную_ модель последовательностей, в чём и заключается реальный пробел в знаниях.
- **Softmax / обычный градиентный спуск с нуля** — этим занимается модуль 08. Здесь softmax — это строительный блок, который вы уже понимаете; новый материал — это autograd, оптимизаторы, регуляризация и BPTT.

# # Концепции

## # 1. Обратное распространение как граф скаляров (Task 1)

Любая нейросеть — это большая составная функция. Обратное распространение — это не что иное, как **chain rule** (правило дифференцирования сложной функции), механически применённое к вычислительному графу.

Представьте каждое промежуточное значение в виде узла, который запоминает, _как оно было получено_. Узел содержит `data` (его значение при прямом проходе), `grad` (∂L/∂data, заполняется позже) и замыкание `_backward`, которое знает, как передать градиент из этого узла к его входам.

Для трёх базовых операций локальные производные таковы:

**Сложение** `c = a + b`. Оба входа влияют на сумму один к одному, поэтому градиент проходит без изменений:

```
∂c/∂a = 1        →   a.grad += 1 * c.grad
∂c/∂b = 1        →   b.grad += 1 * c.grad
```

**Умножение** `c = a * b`. Локальная производная каждого входа равна _другому входу_:

```
∂c/∂a = b        →   a.grad += b.data * c.grad
∂c/∂b = a        →   b.grad += a.data * c.grad
```

**tanh** `o = tanh(x)`. Её производная имеет известное выражение в замкнутом виде через выходное значение:

```
d/dx tanh(x) = 1 - tanh(x)^2 = 1 - o^2
                 →   x.grad += (1 - o.data^2) * o.grad
```

(**relu** `o = max(0, x)` пропускает градиент только там, где вход был положительным:
`x.grad += (x.data > 0 ? 1 : 0) * o.grad`.)

Оператор `+=` важен: если узел передает данные _двум_ последующим потребителям, его градиент представляет собой **сумму**
вкладов (правило дифференцирования сложной функции нескольких переменных). Именно поэтому градиенты накапливаются и должны обнуляться между шагами.

**Обратный проход** инициализирует выход значением `grad = 1` (∂L/∂L = 1), затем обходит каждый узел
в **обратном топологическом порядке**, чтобы градиент каждого узла был полностью накоплен _до_ запуска
его замыкания `_backward` и передачи значений родительским узлам. Топологический порядок — это когда
узел стоит после всех узлов, от которых он зависит; если развернуть порядок, то выходы обрабатываются раньше входов.

Нейрон MLP (многослойного перцептрона) — это `tanh(Σ wᵢ·xᵢ + b)`; слой — это список нейронов; MLP — это стек слоев.
Поскольку каждая операция является `Value`, вызов `.backward()` для значения функции потерь автоматически заполняет `.grad` на
**каждом весе**. Тогда SGD сводится к одной строке на параметр:

```
p.data -= lr * p.grad          # then zero all grads before the next step
```

**Проверка градиентов** — проверка autograd по определению производной (конечные разности):

```
numeric_grad ≈ (f(x + h) - f(x - h)) / (2h)      with small h (e.g. 1e-5)
```

Правильный движок выдаёт для этого ~1e-4.

## # 2. Оптимизаторы и инициализация (Задание 2)

По заданному градиенту `g = ∂L/∂θ` оптимизатор определяет фактический шаг изменения параметров.

**Простой SGD** — шаг строго вниз по склону:

```
θ ← θ - lr · g
```

**Momentum** — поддерживает текущую скорость, чтобы согласованные градиенты набирали её, а шумные — компенсировались:

```
v ← β·v + (1 - β)·g            (β ≈ 0.9)
θ ← θ - lr · v
```

**Adam** — адаптивная скорость обучения для каждого параметра. Отслеживает первый момент `m` (среднее значение градиентов) и второй момент `v` (среднее значение квадратов градиентов), **выполняет коррекцию смещения** обоих (так как они начинаются с 0, ранние оценки смещены к нулю), затем делает шаг:

```
m ← β1·m + (1 - β1)·g
v ← β2·v + (1 - β2)·g²
m̂ = m / (1 - β1^t)            (t = step count, 1-indexed)
v̂ = v / (1 - β2^t)
θ ← θ - lr · m̂ / (sqrt(v̂) + ε)   (β1=0.9, β2=0.999, ε=1e-8)
```

Деление на `sqrt(v̂)` обеспечивает параметрам с большими, шумными градиентами _меньший_ эффективный шаг, а редко обновляемым параметрам — _больший_. Именно поэтому Adam обычно достигает целевой функции потерь за **меньшее число эпох**, чем обычный SGD.

**Инициализация весов.** Если веса слишком велики, активации взрываются; если слишком малы — затухают. Решение — масштабировать начальные случайные веса по fan-in слоя, чтобы дисперсия активаций оставалась примерно постоянной от слоя к слою.

```
He (for ReLU):        W ~ Normal(0, sqrt(2 / fan_in))
Xavier/Glorot (tanh): W ~ Normal(0, sqrt(2 / (fan_in + fan_out)))
```

ReLU (Rectified Linear Unit) зануляет половину своих входов, поэтому ей нужен дополнительный множитель 2 (то есть `2/fan_in`).

**Затухание градиентов.** У сигмоиды `σ(x)=1/(1+e^-x)` производная `σ·(1-σ)`, которая **достигает максимума 0.25** и близка к 0 на хвостах. Backprop умножает один такой множитель на каждый слой, поэтому в глубокой сигмоидной сети градиент первого слоя — это произведение множества чисел ≤ 0.25 → он стремится к нулю, и ранние слои практически не обучаются. Производная ReLU в точности равна 1 для положительных входов, поэтому градиенты проходят без ослабления. В демо выводится норма градиента первого слоя для обоих случаев: **ReLU ≫ sigmoid**.

## # 3. Регуляризация: dropout, batchnorm, L2 (Task 3)

Модель с достаточной ёмкостью запоминает обучающую выборку: **высокая точность на обучении, низкая на тесте**. Этот разрыв и есть то, что сокращает регуляризация.

**Инвертированный dropout.** Во время обучения случайно зануляйте каждую активацию с вероятностью `p`, затем делите оставшиеся значения на `(1 - p)`, чтобы математическое ожидание суммы не изменилось. На этапе тестирования **ничего не делайте** (identity) — масштабирование было уже выполнено на этапе обучения.

```
train:  mask ~ Bernoulli(1 - p);   out = (x * mask) / (1 - p)
test:   out = x
```

Это не дает сети полагаться на какой-либо отдельный нейрон (коадаптация), заставляя её работать как ансамбль подсетей.

**Пакетная нормализация (прямой проход).** Нормализует каждый признак по батчу к среднему 0 и дисперсии 1, а затем позволяет сети масштабировать и сдвигать с помощью обучаемых `γ` и `β`:

```
μ    = mean(x, over the batch)        (per feature)
σ²   = var(x,  over the batch)         (per feature)
x̂    = (x - μ) / sqrt(σ² + ε)
out  = γ · x̂ + β
```

При `γ=1, β=0` на выходе для каждого признака **среднее ≈ 0 и дисперсия ≈ 1** — это критерий
выполнения Task-3. Нормализованные активации удерживают каждый слой в адекватном диапазоне,
что позволяет обучать более глубокие сети с более высоким learning rate.

**L2 weight decay.** Добавьте `(λ/2)·Σ W²` к функции потерь. Её градиент просто равен `λ·W`,
поэтому на каждом шаге вы также подталкиваете веса к нулю:

```
L_total = L_data + (λ/2)·Σ W²
∂/∂W [ (λ/2)·Σ W² ] = λ·W
W ← W - lr·(dW_data + λ·W)
```

Меньшие веса → более гладкая поверхность принятия решений → меньше переобучения. Включение dropout + L2
сокращает разрыв (train_acc − test_acc) по сравнению с нерегуляризованной моделью на том же разбиении.

## # 4. Рекуррентные сети и BPTT (Задание 4)

Последовательности (символы, временные ряды, слова) требуют модель с **памятью**. Обычная RNN (Recurrent Neural Network)
переносит скрытое состояние `h` из одного временного шага в следующий и повторно использует _те же_ веса на
каждом шаге:

```
h_t     = tanh(Wxh · x_t + Whh · h_{t-1} + bh)      hidden state (memory)
logits  = Why · h_t + by                            output scores
p_t     = softmax(logits)                           next-token distribution
```

`Whh` смешивает предыдущую память с текущей, а `Wxh` добавляет текущий вход.
Развернутая на `T` шагов, RNN — это просто очень глубокая сеть прямого распространения, где **каждый слой разделяет одни и те же веса**.

**Обратное распространение во времени (BPTT)** — это обычное обратное распространение на этом развернутом графе. Две вещи делают его особенным:

1. Локальный градиент tanh возникает на каждом шаге: при `h = tanh(a)` выполняется
   `∂L/∂a = (1 - h²) · ∂L/∂h`.
2. Поскольку `Wxh, Whh, Why` **разделяются** на протяжении временных шагов, их градиенты — это **сумма** вкладов каждого шага:

```
for t = T-1 down to 0:
    dy         = p_t - one_hot(target_t)          # softmax+CE gradient (module 08)
    dWhy      += dy · h_tᵀ ;   dby += dy
    dh         = Whyᵀ · dy + dh_next              # output path + gradient from the future
    da         = (1 - h_t²) · dh                  # backprop through tanh
    dbh       += da
    dWxh      += da · x_tᵀ
    dWhh      += da · h_{t-1}ᵀ
    dh_next    = Whhᵀ · da                        # pass memory-gradient to the previous step
```

`dh_next` — это член, который переносит ошибку _назад во времени_ — скрытое состояние на шаге t влияет на функцию потерь на каждом последующем шаге, поэтому его градиент накапливает вклады из всего будущего. (Именно многократное умножение на `Whh` — причина того, что долгосрочные градиенты затухают или взрываются в обычных RNN — это мотивация для появления LSTM (Long Short-Term Memory) / GRU (Gated Recurrent Unit) и, позже, механизма внимания.)

Обученная на короткой повторяющейся строке, RNN усваивает закономерность и предсказывает следующий символ значительно лучше случайного выбора (1/vocab).

## # 5. LSTM и GRU: механизмы gating (гейты), в объеме, достаточном для собеседования (только концепция)

Задание 4 демонстрирует «болезнь» — многократное умножение на `Whh` заставляет долгосрочные градиенты затухать или взрываться. **LSTM (Long Short-Term Memory)** — классическое лекарство, а вопрос «почему LSTM решает проблему затухающих градиентов?» — классика собеседований. Фишка в том, чтобы добавить **cell state** `c_t` — отдельную дорожку памяти, которая обновляется **аддитивно**, тремя обучаемыми сигмоидальными **гейтами** (значения в диапазоне `(0,1)`), которые решают, что проходит дальше:

```
f_t = σ(W_f·[h_{t-1}, x_t] + b_f)        # forget gate: what to erase from c
i_t = σ(W_i·[h_{t-1}, x_t] + b_i)        # input gate:  what new info to write
c̃_t = tanh(W_c·[h_{t-1}, x_t] + b_c)     # candidate content
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t          # ← the additive highway
o_t = σ(W_o·[h_{t-1}, x_t] + b_o)        # output gate: what to reveal
h_t = o_t ⊙ tanh(c_t)
```

Ключевая строка — это обновление состояния ячейки: `c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t`. При обратном распространении градиент умножается на `f_t` (значение, которое сеть может научиться держать близким к 1), а не на `Whh` раз за разом — благодаря этому градиенты могут проходить через множество временных шагов без затухания. Идея аддитивного ярлыка такая же, как и **residual connections** (остаточные связи) в модуле 01d.

**GRU (Gated Recurrent Unit)** — это «бюджетный» LSTM: он объединяет состояние ячейки и скрытое состояние и использует два шлюза (update `z_t`, reset `r_t`) вместо трёх — меньше параметров, обычно схожее качество:

```
h_t = (1 - z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t    # interpolate old state and candidate
```

Выдержки для интервью: LSTM решает проблему исчезающих градиентов благодаря аддитивно обновляемому, защищаемому вентилями состоянию ячейки; GRU — это более дешёвый вариант с двумя вентилями; оба всё равно обрабатывают токены **последовательно** (без параллелизма по временной оси), и именно это «узкое место» трансформеры устранили, заменив рекуррентность механизмом внимания.

1. `dropout_forward(x, p, training)` — инвертированный dropout: маска Бернулли во время обучения, масштабируемая на `1/(1-p)`; тождественная функция при `training=False`.

**Приёмка:**

- Выход batchnorm имеет **покоординатное среднее ≈ 0** (|mean| < 1e-6) и **дисперсию ≈ 1**
  (|var − 1| < 1e-3) при `γ=1, β=0`.
- Обучение **с** dropout + L2 даёт **меньший разрыв (train_acc − test_acc)**, чем
  обучение без регуляризации, на том же разбиении и с тем же сидом.

## # Task 4 🔴 — rnn-bptt

**Цель:** реализовать ячейку ванильной RNN и backprop-through-time; обучить её на крошечной детерминированной задаче предсказания следующего символа, пока она явно не превзойдёт случайное угадывание.

**Файлы:**

- `py/04_rnn_bptt.py`
- `ts/04-rnn-bptt.ts`

**Шаги:**

Корпус (короткая повторяющаяся строка), словарь char↔index, one-hot кодирование, инициализация параметров, выход softmax+cross-entropy, обновление Adam-lite, а также инфраструктура сэмплирования / оценки уже предоставлены. Вы реализуете:

1. `rnn_step(x, h_prev)` — `h = tanh(Wxh·x + Whh·h_prev + bh)`; `logits = Why·h + by`.
2. `forward(inputs, h0)` — разворачиваем `rnn_step` по последовательности, **сохраняя** каждое скрытое
   состояние и вероятности на каждом шаге (нужно для BPTT).
3. `backward(...)` — цикл BPTT: градиент выхода softmax+CE задан; вы заполняете
   **локальный градиент tanh** `(1 - h²)` и **накопление во времени** для
   `dWxh`, `dWhh`, `dWhy`, `dbh`, `dby`, плюс `dh_next = Whhᵀ · da`.

**Критерии выполнения:**

- Функция потерь кросс-энтропии **существенно снижается** в процессе обучения (финальная потеря < ~40% от
  начальной потери).
- На повторяющемся паттерне точность предсказания следующего символа **≥ 0,90** — значительно выше
  случайного базиса `1 / vocab_size` (выводится для справки).
