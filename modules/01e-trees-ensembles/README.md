# # Concepts

## # 1. Деревья решений (CART) и критерий Джини

Дерево решений классифицирует, задавая последовательность вопросов с порогами («`x[0] ≤ 0.8`?»), которые дробят пространство признаков на выровненные по осям блоки; каждый блок предсказывает один класс. Обучение — это **жадное рекурсивное разбиение** (CART, Classification And Regression Trees): в каждом узле перебираем все возможные разбиения, оставляем лучшее и рекурсивно применяем алгоритм к двум половинам.

«Лучшее» требует числовой оценки того, насколько _смешан_ набор меток. **Критерий Джини** (Gini impurity) — это вероятность того, что две выборки с возвращением из узла окажутся разных классов:```
G(y) = 1 - Σ_c p_c²          (p_c = fraction of class c at the node)

pure node (one class):   G = 1 - 1² = 0
balanced binary (50/50): G = 1 - (0.25 + 0.25) = 0.5   (the binary max)
```Разделение отправляет каждую точку влево (`x[j] ≤ t`) или вправо, создавая потомков размеров `n_L`, `n_R`. Его качество измеряется как **взвешенная неоднородность потомков**:```
G_split = (n_L · G(y_left) + n_R · G(y_right)) / (n_L + n_R)
```а **выигрыш** равен `G(parent) - G_split` — та же идея «информационного выигрыша», что и в деревьях на основе энтропии, только с Джини вместо энтропии (они выбирают почти идентичные разбиения; Джини не требует `log`). Разбиение имеет смысл только при положительном выигрыше; если ни одно разбиение не даёт положительного выигрыша, узел становится листом, предсказывающим мажоритарный класс.

В качестве порогов достаточно попробовать только **средние точки между последовательными уникальными отсортированными значениями признака** — любой другой порог даст одно из тех же разбиений.

Если дать дереву расти без ограничений, оно продолжает делиться, пока каждый лист не станет чистым — оно **запоминает обучающую выборку** (train accuracy → 1.0), вместе с шумом. Для зашумлённых данных такое запоминание не обобщается: точность на тесте сильно отстаёт, а разрыв между train и test — видимый признак **переобучения**. `max_depth` и `min_samples_leaf` — регуляризаторы дерева: дерево глубины 3 не может «гоняться» за отдельными шумовыми точками, поэтому разрыв сокращается.

## # 2. Бэггинг и случайные леса

Одно глубокое дерево — это модель с **низким смещением и высокой дисперсией**: если заново сгенерировать обучающую выборку, получится совсем другое дерево. Усреднение — классический способ борьбы с дисперсией — поэтому из одной имеющейся выборки создают много обучающих.

**Bootstrap-выборка** берёт `n` индексов _с возвращением_ из `{0…n-1}`. Вероятность того, что данная строка никогда не будет выбрана, равна```
(1 - 1/n)^n  →  e⁻¹ ≈ 0.368        so ≈ 63.2% of unique rows appear
```(каждый выборочный поднабор, созданный методом bootstrap, поэтому содержит дубликаты — вы выведете это на печать).
**Bagging** (bootstrap aggregating) обучает по одному глубокому дереву на каждом выборочном поднаборе и
усредняет их предсказания, беря большинство голосов. Почему это помогает: для B оценок, каждая с
дисперсией σ² и парной корреляцией ρ,```
Var( (1/B) Σ_b f_b )  =  ρσ²  +  (1-ρ)·σ²/B
```Второе слагаемое исчезает при росте B — а вот первое **не исчезает**. Если все ваши деревья по сути одно и то же дерево (ρ велико), их усреднение почти не помогает. Bagged-деревья _сильно коррелируют_: для первого разделения они жадно хватают один и тот же сильный признак.

Трюк **random forest** бьет по ρ напрямую: при _каждом разделении_ для выбора рассматривается только случайное подмножество из `max_features` признаков. Деревья вынуждены строиться по-разному, ошибкиDecorрелируются, и голосование получает полную пользу от усреднения. Поодиночке «голодные по признакам» деревья _хуже_ (вы увидите их разбросанные по значениям точности), но вместе они побеждают одно глубокое дерево.

## # 3. Градиентный бустинг = градиентный спуск в пространстве функций

Bagging строит сильные обучающиеся алгоритмы **параллельно** и усредняет разброс (дисперсию).
**Boosting** строит слабые обучающиеся алгоритмы **последовательно**, и каждый из них исправляет то, что текущая модель всё ещё делает неправильно — он снижает смещение.

Модель после `m` раундов представляет собой сумму с темпом обучения (shrinkage) `ν`:```
F_m(x) = F_0 + ν · Σ_{k=1..m} h_k(x),        F_0 = ȳ  (the best constant)
```Откуда взялось выражение «fit the residuals»? Рассматриваем предсказания модели
`F(x_i)` как свободные параметры и берём градиент от функции квадратичной ошибки:```
L = ½ Σ_i (y_i - F(x_i))²
-∂L/∂F(x_i) = y_i - F(x_i)      ← the residual IS the negative gradient
```Таким образом, каждый раунд «обучить небольшую модель `h_m` на остатках и добавить немного от неё» — это буквально один **шаг градиентного спуска в пространстве функций** — отсюда и слово «градиент» в градиентном бустинге. (Поменяйте функцию потерь и её антиградиент — логарифмическую функцию потерь, абсолютную ошибку — и тот же цикл даст вам всё семейство GBM (Gradient Boosting Machine); метод наименьших квадратов — это случай, когда антиградиент оказывается равен обычному остатку.)

Слабый обучающийся алгоритм здесь — это **регрессионный пень** (regression stump) — дерево глубины 1: один порог, два значения в листах, каждое из которых равно _среднему_ значению остатков по своей стороне (константа, оптимальная с точки зрения SSE):```
SSE(t) = Σ_{x≤t} (r - mean_left)² + Σ_{x>t} (r - mean_right)²
```Поскольку каждый пень — это наилучший шаг по методу наименьших квадратов, **MSE на обучении никогда не растёт**. MSE на валидации рисует знакомую U-образную кривую: падает, пока ансамбль улавливает сигнал, и растёт, когда начинает захватывать шум. **Early stopping** — остановка на раунде, где MSE на валидации достигает минимума — это основной способ регуляризации в бустинге, наряду с маленьким `ν` (меньшие шаги, больше раундов, лучшая генерализация).

## # 4. Разложение на смещение и дисперсию, измеренное эмпирически

В модуле 01b это разложение было заявлено; здесь вы его _измеряете_. Обучите один и тот же класс модели на `M` независимо пересэмплированных обучающих выборках и оцените все `M` моделей на одной фиксированной тестовой сетке, получая матрицу предсказаний размером `(M × N_test)`. В каждой тестовой точке `x` с чистой целевой величиной `f(x)`:```
mean prediction:  ȳ̂(x)  = (1/M) Σ_m ŷ_m(x)
bias²(x)        = ( ȳ̂(x) - f(x) )²          (systematically wrong)
variance(x)     = (1/M) Σ_m ( ŷ_m(x) - ȳ̂(x) )²   (scattered across retrains)
```Усредняем оба значения по тестовой сетке. Для _зашумлённых_ тестовых меток
`y = f(x) + ε`, `ε ~ N(0, σ²)`, разложение утверждает:```
E[(y - ŷ)²] = bias² + variance + σ²     →    bias² + variance ≈ expMSE - σ²
```а тестовый стенд проверяет это численно. Итоговая таблица:

| model             | bias²                                   | variance                                 |
| ----------------- | --------------------------------------- | ---------------------------------------- |
| stump             | **high** (слишком жёсткий, подстраиваться под данные) | low                                      |
| deep tree         | ≈ 0                                     | **high** (подстраивается под любой шум)  |
| bagged deep trees | ≈ 0                                     | **примерно в два раза меньше**           |

Bagging почти не затрагивает смещение и сильно снижает дисперсию — до корреляционного предела `ρσ²` из Концепции 2; именно поэтому случайные леса поверх этого добавляют подпространственную выборку признаков.

uv run python modules/01e-trees-ensembles/py/01_decision_tree.py
```**TypeScript:** только обычные массивы (без математических библиотек npm). Ничего не собирай, просто запускай.```bash
pnpm tsx modules/01e-trees-ensembles/ts/01-decision-tree.ts
```
