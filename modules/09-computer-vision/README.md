> **Теги глубины** 🟢 app-level · 🟡 build-one-piece-by-hand · 🔴 from-scratch

Визуальные модели превращают пиксели в понимание. В этом модуле вы пройдёте путь от необработанных чисел в JPEG до богатого, гибкого описания от мультимодальной LLM (Large Language Model) — а затем разберём слои, чтобы показать, что происходит внутри CNN (Convolutional Neural Network).

# # Концепции

## # Пиксели → признаки

Цветное изображение — это трёхмерный массив чисел: `height × width × 3` (каналы красного, зелёного и синего), где каждый пиксель — это целое число от 0 до 255. Это сырой вход, который получает каждая визуальная модель. Задача модели — найти структуру — края, формы, текстуры, объекты — в этих числах.

Ранние системы компьютерного зрения вручную создавали такую структуру (границы Собеля, признаки HOG (Histogram of Oriented Gradients)). Глубокое обучение _изучает_ (learns) признаки из данных. Задание 4 в этом модуле реализует детектор границ, созданный вручную, чтобы вы на практике прочувствовали, что такое «признак», прежде чем начнётся обучение.

## # Свёрточные нейронные сети (CNN)

CNN состоит из множества **свёрточных слоёв**. Каждый слой скользит небольшой матрицей (**ядром** или **фильтром**) по картам признаков предыдущего слоя, вычисляя скалярное произведение в каждой позиции. Ранние слои учат низкоуровневые признаки (края, углы); более поздние слои комбинируют их в высокоуровневые паттерны (глаза, колёса, собачьи морды).```
input pixels  →  [conv + relu] ×N  →  global pooling  →  fully-connected  →  label
              (feature maps grow deeper, shrink spatially)
```AlexNet (2012) показал, что глубокая CNN, обученная на ImageNet, способна распознавать 1000 категорий объектов лучше любой системы с ручными признаками. Этот результат положил начало современной эре ИИ.

## # Vision Transformers (ViT)

ViT (Dosovitskiy et al., 2020) применяет архитектуру Transformer, созданную для последовательностей токенов, к изображениям: изображение разбивается на фрагменты фиксированного размера (**patches**, например, 16×16 пикселей), каждый фрагмент разворачивается в вектор, а последовательность векторов фрагментов обрабатывается точно так же, как токены слов в языковой модели. Механизм self-attention позволяет каждому фрагменту «смотреть» на любой другой фрагмент, обеспечивая глобальный контекст, который CNN могут получить лишь с помощью глубокой многослойной структуры.

Модели ViT, обученные в большом масштабе (CLIP, DINOv2, SigLIP), теперь доминируют в бенчмарках классификации и служат основой (backbone) визуального энкодера внутри мультимодальных LLM.

## # CLIP — общее пространство эмбеддингов для изображений и текста

CLIP (Radford et al., OpenAI 2021) обучает визуальный энкодер и текстовый энкодер **совместно** (jointly) с контрастивной целевой функцией: сближать эмбеддинги пары (подпись, изображение) и отдалять всё остальное. После обучения на 400 млн пар из интернета (изображение, альтернативный текст) два энкодера оказываются в **одном и том же пространстве эмбеддингов**: фотография кошки и предложение «a photo of a cat» дают близкие векторы, а «a photo of a dog» — дальше.

Это делает возможной **классификацию zero-shot**: на этапе inference получить эмбеддинг изображения и эмбеддинг текста каждого из кандидатов-меток, затем отсортировать метки по косинусному сходству. Данные для обучения каждого конкретного класса не требуются.```
image encoder ──▶ image embedding ──┐
                                    ├──▶ cosine similarity → ranked labels
text encoder  ──▶ text  embedding ──┘
```### Мультимодальные LLM

Современные LLM (GPT-4o, Claude 3+, Gemini) расширяют архитектуру трансформера, чтобы принимать изображения вместе с текстом. Общая архитектура: предварительно обученный визуальный энкодер (часто ViT-L или ViT-H) преобразует изображение в последовательность «image tokens» (токенов изображения), которые объединяются с текстовыми токенами и передаются в языковую модель. Результат — гибкое понимание: описание, вопросы и ответы, OCR (Optical Character Recognition, оптическое распознавание символов), классификация — и всё это через естественный язык.

## # За пределами абстракции

`llm_core` / `@learn-ai/llm-core` — **только для текста**. Его `ChatMessage.content` — это обычная строка, в нём нет поля для изображений. Отправка изображения в Claude или GPT требует использования «сырых» vendor SDK (Software Development Kits, комплектов разработки) (`anthropic`, `openai`), поскольку мультимодальный формат сообщений — список блоков контента с данными изображения — не является частью общего интерфейса. Именно поэтому Задание 3 использует SDK напрямую. Это не недостаток `llm_core`; это намеренное напоминание, что у каждой абстракции есть граница, и умение определить, где она проходит, — ключевой инженерный навык.

## # Object detection, segmentation, OCR- **YOLO** (You Only Look Once) — обнаружение объектов в реальном времени: ограничивающие рамки +
  метки за один прямой проход.
  [ultralytics.com](https://docs.ultralytics.com)

  [HuggingFace DETR](https://huggingface.co/facebook/detr-resnet-50)
- **SAM** (Segment Anything Model, Meta 2023) — по заданной точке или рамке сегментирует
  объект в этом месте; работает с произвольными изображениями без меток классов.
  [segment-anything.com](https://segment-anything.com)
- **OCR**: традиционный путь — Tesseract; современный путь — мультимодальная LLM (в задании 3
  показано как — достаточно изменить prompt). Для структурированного извлечения данных из документов
  смотрите Microsoft TrOCR или Google Document AI.

## # ViT vs CNN: когда использовать каждую

|                                | CNN                             | ViT                                    |
| ------------------------------ | ------------------------------- | -------------------------------------- |
| Индуктивное смещение (bias)    | Транслиционная эквивариантность (хорошо) | Отсутствует — учитывается из данных    |
| Эффективность по данным        | Лучше на малых датасетах        | Требует большие датасеты или предобучение |
| Глобальный контекст            | Дорого (глубокая иерархия)      | Дёшево (attention глобален по умолчанию) |
| Пропускная способность         | Быстро (оптимизированные ядра CUDA) | Немного медленнее на небольших изображениях |
| SOTA (State of the Art) (2024) | Всё ещё конкурентны (ConvNeXt)  | Доминируют модели на базе ViT          |
