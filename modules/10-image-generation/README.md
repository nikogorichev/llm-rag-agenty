# Модуль 10 — Генерация изображений и диффузионные модели

Stable Diffusion, DALL-E и подобные им инструменты — это не магические фильтры, а вероятностные модели, которые обучаются _обращать процесс добавления шума_. К концу этого модуля вы сгенерируете изображения по тексту через хостинг API (Application Programming Interface), изучите все основные параметры генерации и напишете с нуля минимальный диффузионный сэмплер на NumPy, чтобы понять математику.

# # Концепции

## # 1. Что такое диффузионная модель?

Диффузионная модель обучается устранять гауссов шум. Обучение состоит из двух этапов:

**Прямой процесс (фиксированный, без обучения):**  
Берём реальное изображение x₀. Последовательно добавляем небольшие порции гауссова шума на протяжении T шагов, получая x₁, x₂, …, x_T. На шаге T изображение представляет собой чистый шум — невозможно понять, чем оно было изначально.```
x₀  ──noise──▶  x₁  ──noise──▶  x₂  ──noise──▶  …  ──noise──▶  x_T ~ N(0,I)
```План шума (значения βₜ) определяет, сколько шума добавляется на каждом шаге. Частый выбор — линейный план: β₁ = 0.0001, β_T = 0.02. Поскольку шум накапливается, существует замкнутое выражение:```
x_t = √ᾱₜ · x₀  +  √(1−ᾱₜ) · ε,   ε ~ N(0,I)
```где ᾱₜ = ∏\_{s=1}^{t} (1−βₛ). Это позволяет переходить к _любому_ уровню шума, не симулируя каждый шаг по отдельности.

**Обратный процесс (обучаемый):**  
Нейросеть ε*θ(x_t, t) обучается *предсказывать шум*, который был добавлен для получения x_t из x₀. Используя это предсказание, можно восстановить x*{t−1} согласно правилу обновления DDPM (Denoising Diffusion Probabilistic Model) (Ho et al. 2020):```
x_{t−1} = 1/√αₜ · (x_t − β_t/√(1−ᾱₜ) · ε_θ(x_t,t))  +  σₜ·z,  z~N(0,I)
```Начиная с чистого шума x_T ~ N(0,I) и запуская этот процесс назад на T шагов,
получаем новый sample, похожий на обучающие данные.

## # 2. Latent diffusion (почему Stable Diffusion быстрый)

Запуск диффузии на исходных пикселях (512×512×3 = 786 432 числа) происходит медленно.
Stable Diffusion выполняет диффузию в _сжатом latent space_, который создаётся VAE
(Variational Autoencoder):```
image (512×512×3)  ──VAE encoder──▶  latent (64×64×4)   ← diffusion lives here
                   ──VAE decoder──▶  image (512×512×3)
```Latent-пространство примерно в 48 раз меньше пространства пикселей. VAE заморожен в ходе обучения диффузионной модели; обучается только денойзер (U-Net). На этапе inference вы берёте зашумлённый latent, очищаете его от шума, а затем декодируете в пиксели.

## # 3. Денойзер на основе U-Net

Денойзер ε_θ — это U-Net: свёрточный энкодер-декодер с пропускающими соединениями (skip connections). Он принимает на вход (x_t, t, c) — зашумлённый latent, временной шаг и вектор conditioning c — и выводит предсказанный шум.

Временной шаг t представляется как embedding (синусоидальный, как positional encodings в трансформерах) и подаётся в каждый остаточный блок, чтобы сеть понимала, насколько зашумлён её вход. Вектор conditioning c поступает от текстового энкодера.

## # 4. Текстовый conditioning с помощью CLIP

Stable Diffusion использует замороженный текстовый энкодер CLIP (Contrastive Language–Image Pretraining), чтобы преобразовать ваш prompt в последовательность токен-embeddings c. U-Net обращается к этим embeddings через cross-attention на каждом масштабе, чтобы каждая часть изображения могла «смотреть» на полный prompt.

CLIP обучали выравнивать изображения и подписи в совместном embedding-пространстве, поэтому он «понимает», что «красный мяч» и изображение красного мяча должны быть близки. Текстовая часть энкодера переиспользуется как семантический компрессор для денойзера.

## # 5. Classifier-free guidance (CFG / guidance scale)

Чтобы модель сильнее следовала prompt, денойзер запускается _дважды_ на каждом шаге: один раз с conditioning по prompt, другой — с пустым prompt:```
ε_guided = ε_uncond  +  guidance_scale · (ε_cond − ε_uncond)
````guidance_scale = 1` → отсутствие guidance (модель игнорирует текст); `= 7–8` → сбалансированное соотношение качества/разнообразия; `≥ 15` → строгое следование prompt'у, но перенасыщенность и меньшее разнообразие. Это самый важный параметр генерации.

## # 6. Самплеры и шаги

Обратный цикл DDPM (Denoising Diffusion Probabilistic Models) медленный — для обучения обычно требуется 1000 шагов. Более быстрые самплеры (DDIM, DPM++ 2M, UniPC, LCM) могут выдавать качественные изображения за 20–50 шагов, делая более крупные и умные шаги. Больше шагов = больше деталей, но после ~40 для DPM++ эффект снижается.

| Самплер   | Требуемые шаги | Скорость  | Заметки                                                       |
| ---------- | -------------- | --------- | ------------------------------------------------------------- |
| DDPM       | 1000           | медленная | обучающий самплер; на inference практически не используется    |
| DDIM       | 50             | средняя   | детерминированный при eta=0; хорош для img2img                 |
| DPM++ 2M   | 20–30          | быстрая   | сильный выбор по умолчанию для SD 1.5 / SDXL                   |
| LCM        | 4–8            | очень быстрая | дистиллированная consistency model; небольшая потеря качества |
| SDXL-Turbo | 1–4            | мгновенно | adversarial distillation; лучший быстрый вариант локально      |

## # 7. img2img и inpainting

**img2img:** Исходная точка — _реальное изображение_, зашумлённое до частичного таймстепа (не полностью до T). Денойзер выполняет обратную обработку от этой точки, управляемый prompt'ом. Параметр `strength` определяет, насколько зашумлена исходная точка: `strength = 1` ≈ text-to-image; `strength = 0.3` сохраняет большую часть оригинала.

**Inpainting:** Предоставляется бинарная маска. Зашумлению и очистке подвергается только закрытая маской область; остальное сохраняется. Некоторые модели (SD-inpainting, SDXL-inpainting) были fine-tuning'ованы специально для этого и лучше смешивают края.

## # 8. ControlNetControlNet (Zhang et al. 2023) добавляет дополнительный вход в U-Net: пространственную карту условий — карту границ (Canny), карту глубины, скелет позы человека, набросок и т. д. Дenoiser копирует веса своего энкодера в обучаемую «control»-ветвь, которая обрабатывает пространственный вход и внедряет карты признаков на каждом масштабе U-Net. Это позволяет точно управлять композицией изображения, продолжая при этом следовать текстовому prompt’у.

## # 9. LoRA и DreamBooth fine-tuning

**LoRA (Low-Rank Adaptation):** Вместо того чтобы fine-tune’ить все 900M+ параметров SD, вы добавляете small rank-decomposed matrices (W = W₀ + AB, rank ≈ 4–64) в attention- и feed-forward-слои. Обучение LoRA для нового стиля или концепта занимает минуты на потребительском GPU (Graphics Processing Unit). Во время inference вы «сливаете» (merge) веса LoRA с заданной силой.

**DreamBooth:** Техника fine-tuning’а (Ruiz et al. 2022), которая привязывает новый концепт к редкому токену (например, `sks dog`), используя всего 3–30 референсных изображений, с loss’ом сохранения класса для предотвращения катастрофического забывания. Часто комбинируется с LoRA для эффективности.

## # 10. Image-to-video

Модели вроде Stable Video Diffusion (SVD), AnimateDiff и Runway Gen-3 расширяют пространственный U-Net временными attention-слоями. Прямой/обратный процесс концептуально такой же, но применяется к последовательности latent’ов, которые должны быть временно согласованными. Стоимость inference масштабируется с количеством кадров.

## # 11. Безопасность и водяные знаки

Сгенерированные изображения подвержены рискам злоупотребления (deepfakes, CSAM, дезинформирующий контент). Практические меры защиты включают:

- **NSFW (Not Safe For Work) classifier:** постгенерационный классификатор изображений, который затемняет небезопасный вывод (используется в пайплайне SD по умолчанию).
- **Invisible watermarking:** C2PA/SynthID внедряют невидимые сигналы в пиксельную область или область DCT (Discrete Cosine Transform), чтобы downstream-детекторы могли помечать AI-генерированные изображения.
- **Prompt filtering:** текстовый классификатор блокирует вредные prompt’ы до начала inference.
