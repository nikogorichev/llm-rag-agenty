# tutor — учебная CLI для курса learn-ai

Небольшой автономный консольный тьютор для этого курса. Он умеет две вещи, и обе основаны на README модулей курса:

- **`ask`** — интерактивная Q&A REPL (цикл «чтение—вычисление—печать»). Задавайте любые вопросы о курсе; он объясняет концепцию на нужном уровне и подсказывает, **как приступить к программированию**.
- **`exam`** — оцениваемый тест по модулю: он генерирует вопросы из README этого модуля, задаёт их по одному, затем оценивает ваши ответы, выдаёт балл и советы по учёбе.

Работает **без Claude Code** и **бесплатно на локальной модели Ollama** — общается с моделями через клиент `llm_core`, не привязанный к конкретному провайдеру, поэтому работает с тем `LLM_PROVIDER`, который вы настроили (Ollama, OpenAI, Anthropic, NVIDIA).

> Это также и намеренно проработанный пример: лёгкий **RAG**-пайплайн (discover + retrieve нужный README) плюс оценивание по схеме **LLM-as-judge** — те же паттерны, которые вы собираете вручную в **модуле 05 (RAG)** и **модуле 07 (production)**.
> После этих модулей вернитесь и прочитайте исходный код — всё встанет на свои места.

# # Настройка

Дополнительная установка не требуется — используется корневое окружение курса и общий клиент.```bash
uv sync                       # once, from the repo root
# zero-cost path: install Ollama and pull a model
ollama pull llama3.2
# embeddings improve retrieval but are optional (the CLI falls back to keywords):
ollama pull nomic-embed-text
```Оставьте `LLM_PROVIDER=ollama` в вашем `.env` для бесплатного/локального варианта или установите значение
`openai` / `anthropic` / `nvidia`, чтобы использовать хостинговую модель.

# # Использование

Запускайте команды из этого каталога (`projects/tutor/`) так же, как запускаете проект
`news-agent` — `python -m tutor` ищет пакет `tutor` в текущем каталоге:```bash
cd projects/tutor

# Interactive Q&A REPL (auto-picks the most relevant module per question)
uv run python -m tutor ask

# Focus a module from the start
uv run python -m tutor ask --module 05

# Take a graded 5-question exam on a module (by id, slug, or topic)
uv run python -m tutor exam --module 04
uv run python -m tutor exam --module rag --num 3 --difficulty hard

# List the modules discovered in this repo
uv run python -m tutor modules
```### Команды REPL (внутри `ask`)

| Команда          | Что делает                                           |
| ---------------- | ---------------------------------------------------- |
| `:module <id>`   | Выбрать модуль (например, `:module 04`)             |
| `:module`        | Сбросить выбор — снова автовыбор по вопросу          |
| `:modules`       | Список обнаруженных модулей                          |
| `:help`          | Показать команды                                     |
| `:quit` / `:q`   | Выйти                                                |

## # Флаги `exam`

| Флаг                  | По умолчанию | Значение                                  |
| --------------------- | ------------ | ----------------------------------------- |
| `--module, -m`        | required     | ID модуля (`04`), slug (`05-rag`), тема   |
| `--num, -n`           | `5`          | Количество вопросов                       |
| `--difficulty, -d`    | `medium`     | `easy` \| `medium` \| `hard`              |

# # Заметки и устойчивость

- Отсутствие README модулей обрабатывается корректно (курс собирается постепенно). `ask` предупреждает и отвечает в общем виде; `exam` выводит список доступного.
- Embeddings используются для поиска, если провайдер их поддерживает; иначе выполняется откат на совпадение ключевых слов (поэтому это работает и на Anthropic, у которого нет endpoints для embeddings, а также если не загружен `nomic-embed-text`).
- Для ответов используется стриминг, когда доступен, с откатом на нестриминговый режим.
- Небольшие локальные модели иногда возвращают «грязный» JSON для экзамена; парсинг устойчив к code-блокам и окружающему тексту. Если генерация не удаётся, уменьшите `--num` или используйте более мощный провайдер.
- `Ctrl-C` корректно завершает работу; прерывание экзамена оценивает уже отвеченные вопросы.

# # Два способа интерактивного обучения

Этот CLI — вариант «вне Claude Code / бесплатно на Ollama». Когда вы находитесь **в** Claude Code, slash-команды `/tutor` и `/exam` делают то же самое, но с полноценным agent (причём он может читать и проверять ваши реальные файлы упражнений). Подробнее о том, что и когда использовать — в [`docs/TUTOR_AND_EXAM.md`](../../docs/TUTOR_AND_EXAM.md).
